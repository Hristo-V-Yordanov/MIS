Топология на лабораторна среда - Сесия 1

Виртуални машини

1\. gw (Gateway / Рутер)



&#x20;   Хардуерни ресурси: 1 vCPU, 1 GB RAM



&#x20;   Мрежови интерфейси:



&#x20;       enp0s3 (WAN / NAT): Свързан към интернет (получава IP по DHCP).



&#x20;       enp0s8 (LAN1): Статичен IP 192.168.10.1/24 (вътрешна мрежа LAN1).



&#x20;       enp0s9 (LAN2): Статичен IP 192.168.20.1/24 (вътрешна мрежа LAN2).



&#x20;   Настройки: Включен IP Forwarding (net.ipv4.ip\_forward=1).



2\. srv (Сървър)



&#x20;   Хардуерни ресурси: 2 vCPU, 4 GB RAM



&#x20;   Мрежови интерфейси:



&#x20;       enp0s3 (LAN1): Статичен IP 192.168.10.2/24, шлюз (Gateway) 192.168.10.1 (свързан към вътрешна мрежа LAN1).
