# Упражнение S02 — Разузнаване (Recon)

## 1. Обобщение на средата

- srv (192.168.10.2) — вътрешен сървър в LAN1, зад gw
- gw (192.168.10.1) — рутер/gateway с NAT и IP forwarding
- Открита услуга: Apache httpd 2.4.49 на порт 8080 (CVE-2021-41773)

## 2. Резултати от сканирането

- Откриване на хостове: виж hosts.txt
- Отворени портове: виж ports.txt
- Версии на услугите: виж nmap.txt
- Web enumeration: виж ffuf.txt

## 3. Двата най-големи риска

### Риск №1 — CVE-2021-41773 (Apache HTTP Server 2.4.49 Path Traversal / RCE)

Описание: Уязвимост в нормализирането на пътища в Apache 2.4.49 позволява на нападател да излезе извън webroot директорията чрез последователности като .%2e/ и да чете произволни файлове на сървъра. При включен mod_cgi уязвимостта ескалира до Remote Code Execution.

Доказателство (PoC):
curl -s --path-as-is "http://192.168.10.2:8080/cgi-bin/.%2e/%2e%2e/%2e%2e/%2e%2e/etc/passwd"

Мотивация защо е най-критичен:
- CVSS score: 9.8 (Critical)
- Не изисква автентикация - атаката е еднократна HTTP заявка
- Въздействие: четене на произволни файлове, при mod_cgi - пълен RCE
- Масово експлоатирана публично веднага след публикуване през 2021 г.

### Риск №2 — Липса на host-based филтриране на srv

Описание: srv е директно достъпен от gw без допълнителен firewall (iptables) филтър, което позволява необезпрепятстван достъп до услугите му при компрометиране на друг хост в мрежата.

Мотивация защо е значим риск:
- Увеличава lateral movement потенциала след първоначален пробив
- Комбинирано с CVE-2021-41773, srv може да служи като pivot точка към останалата инфраструктура

## 5. Препоръки за remediation

1. Ъпдейт на Apache до версия >= 2.4.51
2. Изключване на mod_cgi, ако не е нужен
3. Добавяне на iptables правила на srv
4. Редовно сканиране за нови уязвимости
